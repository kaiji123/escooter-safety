# Outputs

Everything here is generated by the scripts in `scripts/`; nothing is edited by hand.
Start with **`index.html`** (overview with links to every page).

```
outputs/
  index.html                          overview of all recordings (scripts/outputs_index.py)
  recordings/<recording>/             one folder per recording (folder name = data/raw/<recording>)
    impact_map.html                   map: route roughness, impacts, detected walking (dashed orange)
    impact_report.html                statistics report
    impact_trace.png                  vertical acceleration and speed over the recording
    fig_*.png                         report figures (severity, per km by road, speed vs severity)
    impacts.csv, impacts_with_roads.csv, impacts_by_road.csv, impact_stats.json, impacts_params.json
    fms_*, impacts_vs_fms.csv         FixMyStreet comparison (each ride vs its own area's reports)
    streetview_check.html (+ .csv)    older Street View checklist (recording 1 only; use combined/spot_links)
  combined/                           all recordings together (scripts/combined_outputs.py)
    combined_map.html                 one layer per recording, walking, spots hit on 2+ rides
    combined_report.html              per-recording and pooled tables, rates by road, hotspots
    impacts_all.csv, summary.csv, by_road.csv, hotspots_all.csv
    spot_links.csv / .html            every spot ranked (tier 1 = hit on 2+ rides) with Google Street
                                      View, Google Maps and Mapillary links (scripts/spot_links.py);
                                      fill in imagery_date, what_visible, notes in the CSV
  sensor_validity/                    data quality and walking detection (scripts/sensor_validity.py)
  scooter_sim/                        Part B dynamics simulation (scripts/scooter_sim.py);
                                      keyframes/ = still-frame figures for the paper (--keyframes)
  wheel_model/                        Part B geometry model (scripts/wheel_geometry.py)
```

## Regenerate

```
python scripts/sensor_validity.py                                   # first: walking bouts for the maps
python scripts/impact_map.py    --data-dir data/raw/<recording>     # -> recordings/<recording>/
python scripts/impact_report.py --data-dir data/raw/<recording>
python scripts/fms_compare.py   --data-dir data/raw/<recording>     # optional
python scripts/streetview_page.py --data-dir data/raw/<recording>   # optional, after fms_compare
python scripts/combined_outputs.py                                  # -> combined/
python scripts/spot_links.py                                        # -> combined/spot_links.*
python scripts/outputs_index.py                                     # -> index.html
```

Without `--data-dir`, the impact scripts use recording 1 (`2026-10-03_1830_rec01`).

## Notes

- Part A uses all three recordings (decided 2026-10-08); report per ride and pooled.
- Road bumps are not in the paper (decided 2026-10-08); their simulation outputs stay in
  `scooter_sim/` as an exploratory record.
- The recordings are not independent (one rider, one phone, overlapping roads), so
  pooled rates in `combined/` are descriptive.
- Maps and reports contain exact ride coordinates. Keep them local unless sharing is
  decided, and trim the start and end of each route first.
- The Street View page keeps entries in the browser (`localStorage` key
  `streetview-check-v1`). Use its Export CSV button to save them to
  `data/streetview_observations.csv`.
